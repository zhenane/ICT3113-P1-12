# Prediction Record

Step 4 deliverable. Committed together with `../golden-test-set/final/`
**before the first benchmark run**, and never revised afterwards. The commit
history is the evidence that these predictions predate measurement.

Must state, specifically enough to be provably wrong:
- Where the bottleneck is expected to be under load, and why.
- Per candidate model: expected classification accuracy on the golden set,
  and expected single-request latency on the team's hardware.
- Which categories are expected to be hardest to classify, and why.

Marks reward specificity and an honest account later (Slide 11) of where the
predictions were wrong — not being right.
