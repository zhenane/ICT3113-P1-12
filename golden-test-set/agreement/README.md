# Inter-Annotator Agreement

The computed agreement statistic (e.g. Cohen's kappa / Fleiss' kappa /
raw percent agreement — justify the choice) comparing the independent label
sheets in `../labels/`.

Also record every disagreement and how it was resolved by discussion
(this doubles as input to the protocol revision log). A golden set with
implausibly perfect agreement and no recorded resolutions will be examined
closely — so keep this honest and complete.
