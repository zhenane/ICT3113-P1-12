# Workload Model

Step 3 deliverable: quantitative estimates of the client's workload, each
figure cited to a public source where possible (e.g. published complaint
volume statistics for a financial services complaints desk), or clearly
marked as an estimate with the estimation method explained.

Must cover:
- Ticket volume over a relevant period.
- Rate of agent-side searches (`GET /search`).
- Peak vs. non-peak periods, if they exist.
- Expected distribution of ticket lengths.

This feeds directly into `../requirements/`.
